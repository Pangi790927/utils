# templates

Files meant to be copied and edited, never used as they stand.

`claude_md/` holds CLAUDE.md examples. A CLAUDE.md is read into context at the start of every
session in that repo, so it is worth keeping short: what this repo is, how it is built, what a
contributor is expected not to do. Anything longer belongs in a skill, which is only loaded when it
is relevant.

`project_init/` holds ways of setting a project up so that working on it with Claude is pleasant:
which files to create, what to put in them, and in what order.
